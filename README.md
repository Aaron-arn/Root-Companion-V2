# Root Companion

![Root Companion](assets/banniere.png)

**Compagnon de bureau intelligent** — Hackathon MakersHub 2026

Root est un sprite qui vit sur ton bureau. Tu peux le déplacer, lui parler, et il répond grâce à une IA intégrée. La fenêtre est transparente et click-through : tu peux cliquer sur les fenêtres derrière Root !

**Installation manuelle**

```bash
# Installer les dépendances
npm install

# Lancer en développement
npm start
```
